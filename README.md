# 這算出軌嗎？ / これって浮気？

繁體中文與日語雙語戀愛界限判定表，適用於聊天、直播和朋友間的交流。

網站：**https://liuchenhsiung.github.io/uwaki-sheet/**

- 左上角單鍵切換繁體中文／日本語，保留目前題目、所有答案和換位思考答案。
- 保留參考網站的置中窄版、灰底粉字、兩側粉色竪線、原版字體和按鈕樣式。
- 40 道三選一題目，以及獨立的換位思考題；支援點選選項自動進入下一題、整表填寫和修改答案。
- 繁中按台灣語境意譯：SNS → 社群網路，カラオケ → KTV 唱歌。日語保留原題。
- 瀏覽器自動儲存；沒有帳號、後端、統計或答案上傳。清空答案前會提示。
- 判定類型和分值區間沿用參考網站；支援儲存結果圖、三頁完整判定表 PNG 和複製結果文字。
- 結果頁提供 X、Facebook 和IG分享入口。Facebook／IG按鈕會複製目前文案、下載結果圖，並打開對應發布頁；使用者自行貼上文案、加入圖片和發布。剪貼簿不可用時，可複製頁面中的文案。
- 手機與桌面自適應；支援鍵盤、螢幕閱讀器和減少動畫偏好。

## 本機使用

無第三方相依性。直接打開 `public/index.html` 也可填寫；推薦使用 Node.js 20+ 啟動靜態服務：

```sh
npm start
```

訪問 http://127.0.0.1:4173

檢查資料及存檔邏輯：

```sh
npm test
```

## GitHub Pages

這是靜態站點。儲存庫的 Settings → Pages → Source 選擇 **GitHub Actions**，推播到 `main` 後會自動驗證並部署 `public/`。沒有建置相依性，也不需要付費服務。修改網域或儲存庫名時，同步更新 README、`public/app.js` 的原始碼連結和圖片頁尾。
